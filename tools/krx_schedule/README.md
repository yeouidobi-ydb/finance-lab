# krx_schedule

특정 날짜가 KRX 휴장일인지 조회하고, 그 날짜가 들어간 공지를 함께 보여 준다.
Python과 Rust 버전이 같은 결과를 출력한다.

## 실행

```bash
# Python (표준 라이브러리만 사용)
python krx_schedule.py 2026-12-25

# Rust
cargo run --release -- 2026-12-25
```

날짜를 생략하면 오늘(KST)을 조회한다. 다른 Python 스크립트에서는 `from krx_schedule import is_trading_day`로 쓸 수 있다.

## 출력 판정

- `휴장 (주말)` / `휴장 (<휴장일 이름>)` / `개장`
- KRX 조회가 실패하거나 휴장일 목록이 비어 있으면 "휴장일 없음"으로 넘기지 않고 오류(종료 코드 1)로 멈춘다.

## 알려진 한계

- **공지 출처:** `strn.krx.co.kr/corebbs5/BHPSTRN0401`은 **KRX 개인 공매도 모의거래인증시스템** 게시판이다. 수능일 같은 날 공지가 올라오기는 하지만 정규장 시간 변경 공지가 아니다. 그래서 "참고 공지"로만 표시하고 판정에는 쓰지 않는다.
